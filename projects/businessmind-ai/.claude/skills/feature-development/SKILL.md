Skill: Feature Development
 
Objetivo
 
Desenvolver funcionalidades de software com código organizado, funcional, seguro e alinhado aos requisitos do projeto.
 
Responsabilidades
 
- Implementar funcionalidades planejadas.
- Criar e modificar componentes.
- Integrar frontend, backend e banco de dados.
- Corrigir erros durante o desenvolvimento.
- Manter consistência com a arquitetura.
- Documentar alterações importantes.
Método de trabalho
 
1. Ler os requisitos e critérios de aceitação.
2. Consultar a arquitetura e as decisões técnicas.
3. Analisar o código existente antes de modificar.
4. Dividir o trabalho em pequenas tarefas.
5. Implementar uma funcionalidade por vez.
6. Executar testes após cada alteração relevante.
7. Corrigir problemas encontrados.
8. Atualizar a documentação.
9. Registrar arquivos modificados e resultados.
Regras de desenvolvimento
 
- Não reescrever partes funcionais sem necessidade.
- Não remover funcionalidades existentes sem autorização.
- Não inventar APIs, bibliotecas ou dependências.
- Não deixar código incompleto sem informar.
- Evitar duplicação e complexidade desnecessária.
- Tratar erros e entradas inválidas.
- Proteger dados e credenciais.
- Respeitar os padrões definidos pelo projeto.
Controle de alterações
 
Ao concluir cada tarefa, informar:
 
- O que foi implementado.
- Quais arquivos foram criados ou alterados.
- Quais decisões técnicas foram tomadas.
- Quais testes foram executados.
- Quais problemas permanecem.
- O que deve ser feito em seguida.
Entregáveis
 
- Código-fonte funcional.
- Componentes e módulos.
- Integrações implementadas.
- Testes relacionados à funcionalidade.
- Documentação atualizada.
- Registro das alterações.
Integração com outras Skills
 
Trabalhar em conjunto com:
 
- Business Analysis.
- Software Architecture.
- Code Review.
- Quality Assurance.
Critério de conclusão
 
Uma funcionalidade estará concluída quando atender aos requisitos, respeitar a arquitetura, passar pelos testes aplicáveis e ter suas alterações documentadas.

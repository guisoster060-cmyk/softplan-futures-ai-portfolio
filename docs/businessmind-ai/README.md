# BusinessMind AI — Documentação

Este diretório reúne a documentação, as decisões, as instruções de desenvolvimento e o histórico de evolução do BusinessMind AI.

## Documentos do projeto

- PROJECT_BRIEF.md — visão geral e objetivos.
- PROJECT_STATUS.md — situação atual e progresso.
- DEVELOPMENT_RULES.md — regras de desenvolvimento.
- TECHNICAL_DECISIONS.md — decisões técnicas.
- MARKET_VALIDATION.md — documentação da pesquisa documental e da etapa inicial de validação com formulário.
- PROMPT_LOG.md — histórico geral de prompts.
- CHATGPT_PROMPT_HISTORY.md — histórico de contribuições do ChatGPT.
- AGENTS.md — orientações para agentes de IA.
- CLAUDE.md — instruções para o Claude.

## Skills

As definições das Skills ficarão organizadas em `.claude/skills/`.

## Princípio de documentação

Decisões, alterações, testes e contribuições de IA devem ser registrados. Informações não verificadas devem ser identificadas como hipóteses, nunca como fatos.
